## Overview

Eclipse Temurin JDK is an OpenJDK-based Java runtime concept built around free, cross-platform, TCK-certified binaries. It brings together HotSpot VM optimizations, Shenandoah GC, and long-term support into a single distribution for enterprise and development environments .

---

## Essential Eclipse Temurin Features

- **OpenJDK-Based Binaries:** Prebuilt OpenJDK binaries available free of charge without usage restrictions on a wide range of platforms .
- **TCK Certified:** Passed Java SE Technology Compatibility Kit testing and AQAvit verification for production use .
- **Cross-Platform Consistency:** Consistent behavior and builds across major operating systems and hardware architectures .
- **Long-Term Support:** LTS versions (8, 11, 17, 21, 25) supported for at least four years, with quarterly security updates .
- **HotSpot VM:** Includes HotSpot virtual machine with JIT compilation and garbage collection tuning for performance .
- **Shenandoah GC:** Available from Java 11 onward for low-pause garbage collection .

---

## What Eclipse Temurin Brings to Java Workflows

The distribution provides a standards-compliant Java runtime for development and production. Its structure supports both individual developers and enterprise deployments.

Free availability removes licensing barriers. All binaries are available without cost or usage restrictions, making them suitable for development, testing, and production environments .

TCK certification ensures compatibility. Applications built and tested against Temurin follow the Java SE specification, reducing platform-specific surprises .

LTS versions provide stability for long-term projects. Java 8, 11, 17, 21, and 25 receive extended support, giving teams a defined code stream and time to migrate between LTS releases .

Quarterly updates follow the OpenJDK schedule. Security patches and maintenance releases arrive on the third Tuesday of January, April, July, and October, with Temurin binaries following shortly after the upstream releases .

Container images simplify deployment. Official Temurin images are available on DockerHub for all supported JDK versions, with Ubuntu-based images and support for aarch64, arm, ppc64le, s390x, and x64 architectures .

Reproducible builds add supply chain confidence. Temurin JDK 21+ builds are fully reproducible, and third parties can independently verify and attest to the builds .

## Starting an Eclipse Temurin Session

**Prerequisites:** A compatible device, the Temurin build for your platform, and a Java application or development project.

1. **Check Compatibility:** Review the supported platforms and JDK versions for the current release .
2. **Obtain Access:** Use the GET button above to reach the designated project destination and review available information.
